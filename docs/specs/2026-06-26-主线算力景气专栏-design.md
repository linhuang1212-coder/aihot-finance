# 主线·算力景气 专栏 设计文档

> 舆情系统 · 投资主线增强。2026-06-26。

**Goal:** 把用户投资主线(AI 算力全产业链"卖铲子传导":需求→晶圆/制程产能→存储/HBM涨价→先进封装→上游电力/能源,叠加国产替代+政策催化)的信号**单独露出来**:① 侧栏加「主线」专题栏只看这条链;② 扩充 `THEME_KW` 词表,让全站打分/精选更准地把这类新闻浮上来。

**缘起:** 用户朋友连发 8 条(苹果M7AI芯片/微软内存+2.5倍/长鑫追美光/台积电N2产能+70%/苹果内存涨20%/西电东送/能源×算力协同/…),全是"沿 AI 算力链的供给·产能·成本·涨价量级拐点"——正是用户记忆里的主线框架 `GPU→存储/HBM→光→上游铜/电力/核电/数据中心`。现有 `THEME_KW` 已含一半地基,但只埋在打分里、没单独露出。

---

## 锁定的设计决策

| 决策 | 选择 |
|---|---|
| 判据 | **复用 `THEME_KW`**(本就是主线词表):抓取时给命中任一 THEME_KW 词的条目打 `it["mainline"]=True` |
| 词表 | 在现有 THEME_KW 上**扩充**链条词(产能/先进封装/上游能源/国产替代/政策),一套词既调打分又当筛子 |
| 侧栏 | 「视图」组加「主线」一项(`view="mainline"`),`mode=all` + `mainline=1` |
| 过滤位置 | 服务端 `filter_items` 加 `mainline` 参数(读 `it["mainline"]` 标记,O(1)) |
| 范围 | 全信源(金十+X 都算);只盯 AI 算力链,**不含**油/中东等风险罩 |

## 词表扩充(`newsfetch.THEME_KW`)

在现有键(涨价/提价/缺货/紧缺/短缺/供不应求/缺口/停产/减产/shortage/price hike/hbm/存储芯片/光模块/先进封装/cpo/石英砂/光棒/光刻/晶圆/制程/2nm/3nm/良率/封测/光纤/光伏/储能/锂电/固态电池/风电/数据中心/算力/液冷/idc/出口管制/实体清单/对华关税/芯片法案/export control)之上新增(英文键小写):

```python
    # 卖铲子传导补强(2026-06-26):产能 / 先进封装 / 上游电力能源 / 国产替代
    "产能": 1, "扩产": 2, "cowos": 2, "soic": 1, "先进制程": 1,

```

> **剔除项(精度,实测/复核后定):**
> - `a16` —— 撞 "a16z"(VC 机构),产能信号已由 `产能/先进封装/cowos` 覆盖。
> - `核电` —— 线上冒烟实测:裸"核电"命中**扎波罗热核电站战争抢修**(地缘风险罩,非 AI 主线),top8 占 3 条。上游能源已由 `特高压/西电东送/可控核聚变/超导` 覆盖。
> - `十五五` —— 五年规划跨全行业(医疗/农业…);新型能源体系那条已由 `西电东送/算力枢纽/可控核聚变` 命中,无需裸键。
> - 不加 `内存/电力/dram`(误命中多);涨价角度已有 `涨价/提价/缺货`。

## mainline 打标(`newsfetch`)

```python
def _tag_mainline(it):
    """命中任一主线词(THEME_KW)-> it["mainline"]=True;供「主线」专栏筛选。"""
    text = _all_text(it)
    it["mainline"] = any(k in text for k in THEME_KW)
```

在 `fetch_all` 的 `for it in items: _tag_entities(it)` 循环里顺带调用(同一轮文本已就绪)。`public_item` 透传 `mainline`。

## 后端(`server.py`)

`filter_items` 加 `mainline` 参数,与 `stock` 同级:

```python
mainline = qs.get("mainline", [None])[0]
...
if mainline and not it.get("mainline"):
    continue
```

主线栏请求 `/api/public/items?mainline=1&mode=all`。

## 前端

### index.html
「视图」组里(`全量` 之后)加:
```html
<a class="nav-item" data-view="mainline">主线</a>
```

### app.js
- `VIEW_TITLES` 加 `mainline: "主线"`;`VIEW_KICKERS` 加 `mainline: "Mainline · 算力景气"`(新皮肤有 kicker);`FEED_VIEWS` 加 `"mainline"`。
- `buildItemsUrl`:`else if (state.view === "mainline") { p.set("mode", "all"); p.set("mainline", "1"); }`。
- 复用分页/市场筛选/隐藏未证实/自动刷新;`setActiveNav`/标题现有逻辑兼容(无子键)。

## 边界
- 旧库条目没有 `mainline` 标记(抓取时才打)→ 主线栏只覆盖打标后新抓的,旧的随时间补齐/老化;可接受。
- `THEME_KW` 扩充后打分略变(更多条目命中主线加权,封顶 `THEME_BOOST_CAP=4.0` 不变)。
- 零依赖照旧。

## 不在本期范围
- 风险罩(中东/油/美联储)单独栏。
- 主线再细分子链(存储/光/电力分开)。

## 测试(TDD,stdlib unittest)
1. `newsfetch`:`_tag_mainline` —— 含主线词("台积电产能扩产"/"内存涨价"/"国产替代")→ `mainline=True`;纯无关("某球员转会")→ False。THEME_KW 含新键(如 "特高压""国产替代")。
2. `server.filter_items`:`mainline=1` → 只回 `it["mainline"]` 为真的;无参数不受影响。
3. 前端:人工(node 语法 + 浏览器看「主线」栏)。

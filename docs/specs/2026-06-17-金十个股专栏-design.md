# 金十个股专栏 设计文档

> 网页前端 · 子功能。2026-06-17。

**Goal:** 左侧「信源」组(金十/X 下面)新增 **「个股」** 栏,显示金十里**A股个股**相关的条目(全量),方便单独扫个股公告/异动。

**背景(代码探查):** 金十 `_jin10_entities` 从 remark.quotes 抽个股 → `{name, code, market}`,market 映射 SZ/SH/BJ→`a-share`、HK→`hk`、其余→`us`(其中 `us` 混了原油/黄金等商品行情)。实测最新100条金十里 a-share 个股实体约 7 条。用户确认:**只要 A股,不要港股**。

---

## 锁定的设计决策

| 决策 | 选择 |
|---|---|
| 识别 | `source=="金十"` 且任一实体 `market=="a-share"`(精准:个股,排除港股/美股/商品) |
| 显示 | **全部**(`mode=all`),配合分页扫所有 a股个股 |
| 位置 | 「信源」组,金十/X **之后**,标签「个股」 |
| 过滤位置 | 服务端 `filter_items` 加 `stock` 参数 |

## 后端(server.py)

`filter_items` 加 `stock` 参数,与现有 `source` 同级:

```python
stock = qs.get("stock", [None])[0]
...
# 循环内:
if stock and not any(e.get("market") == "a-share" for e in it.get("entities", [])):
    continue
```

个股栏请求 `/api/public/items?source=金十&stock=1&mode=all`。

## 前端

### index.html
「信源」组(金十/X 那两项之后)加:
```html
<a class="nav-item" data-view="stock">个股</a>
```

### app.js
- `VIEW_TITLES` 加 `stock: "个股"`;`FEED_VIEWS` 加 `"stock"`。
- `buildItemsUrl`:`else if (state.view === "stock") { p.set("mode", "all"); p.set("source", "金十"); p.set("stock", "1"); }`(放在 source 分支附近)。
- 导航点击/`setActiveNav`/标题:`view==="stock"` 无 data-source,现有逻辑天然兼容(`setActiveNav` 只在 category/source 时比子键;标题 `VIEW_TITLES["stock"]` 即「个股」)。无需额外改这三处(除 VIEW_TITLES/FEED_VIEWS/buildItemsUrl)。
- 复用市场 chip / 隐藏未证实 / 分页「加载更多」/ 45s 自动刷新。

## 边界

- 偶有"只提到指数(如科创50,也带 a股代码)"的条目会被算进个股 —— 极少,且多数仍是个股公告,可接受。
- 个股栏暂无内容 → 显示现有「没有匹配的条目」。
- 零依赖照旧。

## 不在本期范围

- 港股/美股个股(用户明确只要 A股)。
- 指数 vs 个股 的精确区分(YAGNI)。
- 对金十以外信源套用 stock 过滤。

## 测试(TDD,stdlib unittest)

`filter_items` 的 `stock` 过滤(构造 server.ITEMS 直测):
1. `stock=1` → 只回带 `market=="a-share"` 实体的条目;无 a股实体的(纯宏观/商品/港股实体)不中。
2. `stock=1 & source=金十` → 叠加:只回金十 + a股个股。
3. 无 `stock` 参数 → 不受影响(向后兼容)。

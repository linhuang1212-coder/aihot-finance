# X 同事件多推合并 设计文档

> 舆情系统 · X 信源增强。2026-06-15。

**Goal:** 同一个 X 账号短时间连发、讲同一事件的多条推文(如 Clash Report 连发 4 条 Araghchi 表态),在数据管线里**合并成一条 item**(各条陈述作为 `segments` 竖排),让网页卡片和 Telegram 推送都呈现合并后的一条,不再刷屏。

**关键事实(2026-06-15 实测 twitterapi 响应):**
- 响应**有** `conversationId`/`inReplyToId`/`isReply`/`quoted_tweet` 等字段,但 **Clash Report 这类连发是独立推文**(`conversationId==自己id`、`isReply=False`)——**不是回复线程**,无法靠会话字段归组。
- 这类账号格式固定为「**{人物/主题}:\n{一句陈述}**」,连发数条**共享开头主语行**(如连续都以 `French far-right leader Jordan Bardella:` 开头)→ 这是可靠的启发式信号。

---

## 锁定的设计决策

| 决策 | 选择 |
|---|---|
| 合并层 | **数据管线**(`newsfetch.fetch_all` 抓取后、聚类前)→ 网页+推送都自动是合并版 |
| 同事件判据 | **同 `X·` 账号 + 同主语行 + 同批次(近几分钟)** + ≥2 条 |
| 主语提取 | 从 `title_orig`(原文)取首行 → 去 `BREAKING:/快讯:/突发:` 等前缀 → 该行以 `:` 结尾则取冒号前为主语 → 归一化;**非此格式 → None,不合并** |
| 合并后内容 | 躲开 LLM 覆盖 `summary_zh`:用**新字段 `segments`(各条陈述列表)**承载;`title_zh`=首条 |
| 渲染 | 网页 `cardNode` + Telegram `render_push_item` 各加一处:有 `segments` 则竖排显示 |
| 范围 | **仅 X**;单条/非X/不合并格式 → 原样;不跨抓取周期合并(MVP) |

## 主语提取 `newsfetch._x_subject(text)`

```python
_X_PREFIX_RE = re.compile(r"^\s*(breaking|just in|update|快讯|突发|独家|重磅|最新)\s*[:：]\s*", re.I)

def _x_subject(text):
    """从推文原文取「主语行」用于同事件聚合;非「{主语}:」格式 -> None。"""
    line = (text or "").split("\n", 1)[0]
    line = _X_PREFIX_RE.sub("", line).strip()
    # 仅当首行以冒号结尾(中英文冒号)= 主语行;取冒号前。保守:避免 "Breaking news: ..." 误判
    if line.endswith(":") or line.endswith("："):
        subj = line[:-1].strip()
        return subj.lower() if subj else None
    return None
```

> 取 `title_orig`(原文)而非译文:译文会因翻译波动主语不一致;原文主语稳定。

## 合并 `newsfetch._merge_x_bursts(items)`

```python
X_MERGE_WINDOW_MIN = int(os.environ.get("X_MERGE_WINDOW_MIN", "120"))  # 同组时间跨度兜底
```

- 只对 `source` 以 `"X·"` 开头的条目尝试合并;其余原样保留。
- 按 `(source, _x_subject(title_orig))` 分组(subject 为 None 的不参与)。
- 每组若 `>=2` 条 **且** 组内 `published_at` 跨度 `<= X_MERGE_WINDOW_MIN` 分钟 → 合成一条;否则各条原样。
- 合并条目(组内按 `published_at` 升序):
  - `title_zh` = 组内首条 `title_zh`(自带完整一句,作标题)
  - `segments` = 其余各条 `title_zh` 列表(后续陈述;首条已在标题)
  - `title_orig` / `body_excerpt` = 各条原文换行拼接(截 500)
  - `source` / `source_url`(首条) / `lang` / `verified` / `channels` 取首条
  - `published_at` = **最晚**(让合并条在信息流里保持新鲜、不被首条时间压到下面);`id` = `_hash_id("xmerge:" + source + subject + 最早published_at)`(不同时段的同主语突发 → 不同 id,不会经 id-dedup 误并)
  - `dedup_group` = `_hash_id(_norm_title(首条 title_zh))`
  - `categories/markets/entities/tags` 留空(管线重新打标);`heat/read_count` 缺省
- 返回新 items 列表(合并条 + 未合并条)。

## 管线接入(`newsfetch.fetch_all`)

抓取段之后(`items.extend(xfetch.fetch_x())` 之后)、`for it in items: _tag_entities(it)` 之前,加一行:

```python
    items = _merge_x_bursts(items)
```

之后翻译已在 xfetch 完成;`_tag_entities`/`_keep`/`_cluster`/`llm.enrich`/打分/`mentions`/推送全部对**合并条**自然生效(一个事件一个重要度/情绪)。

## xfetch 顺带捕获 `conversationId`

`xfetch._to_item` 的返回 dict 加一项 `"conversation_id": tw.get("conversationId")`(给"真线程账号"留后路;本期合并不依赖它)。`public_item` 透传无妨。

## 渲染(有 `segments` 时竖排)

### 网页 `public/app.js` `cardNode`
现有:`if (it.summary_zh) card.appendChild(el("div","card-summary",esc(it.summary_zh)));`
改为:**若 `it.segments?.length`** → 渲染 `.card-summary`(首条已是 title,segments 作后续)每段一个 `.card-seg` div;**否则**维持原 summary 渲染。

### Telegram `telegram_bot.py` `render_push_item`
`sm` 那段:**若 `it.get("segments")`** → 把各段各占一行(`\n` 连接,转义)作为正文;否则维持原 `summary_zh` 逻辑。

### CSS `public/style.css`
加 `.card-seg { ... }`(每段一行、缩进/前缀点,复用 `--text-dim`)。

## 边界与降级
- 不合并格式(无"{主语}:")/单条 → 原样单发,行为不变。
- 跨抓取周期掉队的同主语推文 → 单独成条(MVP 不跨周期合并)。
- 主语误合风险:同账号同主语但实为不同事件(罕见,且有 ≤120 分钟跨度兜底);代价仅"多并一条",可接受。
- LLM enrich 仍跑(读 `title_zh[:80]`=首条),给合并条一个事件级重要度/情绪;`segments` 不被覆盖。
- 零依赖照旧。

## 不在本期范围
- 跨抓取周期合并(掉队推文事后并入已有合并条)。
- 用 `conversationId` 合并真线程账号(字段已捕获,留后续)。
- LLM 判定同事件 / 对金十等其它源套用。

## 测试(TDD,stdlib unittest)
1. `_x_subject`:`"Iran's FM Araghchi:\nWe ..."`→`"iran's fm araghchi"`;`"BREAKING: Jordan Bardella:\n..."`→去前缀后主语;`"*FED CUTS RATES"`(无冒号格式)→`None`;空→`None`。
2. `_merge_x_bursts`:
   - 同账号同主语 3 条 → 合 1 条,`segments` 含其余 2 段,`title_zh`=首条,`published_at`=最早。
   - 同账号不同主语 → 不合(各自保留)。
   - 非 X 源(金十)同主语 → 不合。
   - 单条 X → 原样。
   - 跨度 > 窗口 → 不合。
3. 渲染:`render_push_item` 有 `segments` → 输出含各段、各占一行;无 `segments` → 维持原样(回归)。

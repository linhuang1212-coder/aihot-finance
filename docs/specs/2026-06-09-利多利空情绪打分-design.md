# 利多利空情绪打分 设计文档

> 舆情系统演进 · 子项目 1（投资自用视角）。2026-06-09。

**Goal:** 给每条去重后的新闻打一个**方向性情绪**标签——对某标的/板块是利多、利空还是中性——让用户一眼看出"这条消息对我的持仓是好是坏"。

**定位:** 项目是舆情系统而非单纯聚合器；自用投资决策；情绪定义为**利多利空(方向性)**而非通用正负面；引擎**复用已接入的 DeepSeek**。

---

## 锁定的设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 情绪定义 | 利多 / 利空 / 中性（方向性） | 同一条对不同标的方向相反，通用正负面没用 |
| 引擎 | 复用 `llm.enrich` 同一次调用 | 无额外请求、无额外成本，沿用现有缓存 |
| 强度 | 1–3 | 1–5 是虚假精度；1–3 映射动作（留意/关注/重磅） |
| 中性处理 | 情绪轴不加不减分 | 中性≠不重要；重磅宏观常中性，重要度仍由 `llm_importance` 管 |
| 自选标的 | 涉及自选股时 `tgt` 优先给该股 | 让利多利空成为可执行的持仓信号 |
| 降级 | 无 LLM → 无情绪 | 与现有 `llm` 自动跳过一致 |

## 数据模型

`llm.enrich` 返回的每条 JSON 新增 3 字段，随现有字段一同缓存：

| 字段 | 含义 | 取值 |
|---|---|---|
| `dir` | 方向 | `利多` / `利空` / `中性` |
| `tgt` | 对谁 | 受影响板块/标的短串（如「存储芯片」「黄金」）；中性可空 |
| `str` | 强度 | `1`–`3` |

落到条目：`it["sentiment"] = {"dir","tgt","str"}`（中性时 `tgt` 允许空）。

## Prompt 改造（`prompt_pack.md`）

核心教会模型**判断方向对谁**：
- 「上游涨价 → 对上游/供给方利多、对下游/采购方利空」
- 「制裁/管制 → 对受限方利空、对替代标的利多」
- 纯宏观无单一标的指向 → `中性`
- **若新闻涉及给定自选标的，方向针对该标的给**
- 把握不足时给 `中性`，不强行编方向（防幻觉）

JSON schema 增补 `dir/tgt/str`；`_FALLBACK_PACK` 同步更新。

## 打分集成（`newsfetch._score` / llm 分支）

- `dir` ∈ {利多,利空} 且 `str==3` 且条目命中自选实体 → `+1.0`（封顶，保守）
- 中性 → 不动分
- 不改变现有 `llm_importance` 主导逻辑

## 展示

- **前端卡片**：`利多🔴` / `利空🟢` chip（A 股语境**红涨绿跌**：利多=红、利空=绿）+ `tgt`；中性不显 chip
- **Telegram 推送 — 分组式重排**（用户 2026-06-09 选定，替换旧的 nvidia/其他 二分）：
  ```
  📊 新消息 · N条   🔴a 利多  🟢b 利空
  ━━━ 🔴 利多 ━━━
  🔥 <标题>
     <摘要>  〔📌 自选标的〕
     <来源> · <时间>
  ━━━ 🟢 利空 ━━━
     ...
  ━━━ ⚪ 关注 ━━━           ← 中性 + 无情绪(LLM关)条目
     ...
  ```
  - 分组 = `sentiment.dir`：利多→🔴组、利空→🟢组、中性/无情绪→⚪关注组
  - 行首 🔥 = 有热度(沸/爆/火/热)
  - 〔📌 …〕= 命中的实体/自选标的；无则省略
  - `⚠️` 未证实标记保留（附在标题后）
  - 组内保持入站顺序（已按分数/时间排好）；空组不显示
- LLM 关闭时：所有条目落「⚪ 关注」组，退化为「热度+标题+摘要」，不报错

## 不在本期范围（MVP 边界）

- 多标的方向（一条对多个标的分别打）→ 后续
- 整体「市场情绪 risk-on/off」叠加层 → 后续
- 传播热度曲线 → 子项目 2

## 测试（TDD，stdlib unittest）

1. `llm.enrich` 解析并应用 `dir/tgt/str`（mock API 返回）
2. 缓存命中不重复调用、字段持久
3. `_score`：利多+str3+自选实体 → 加分；中性 → 不加分
4. 降级：无 key → 无 sentiment 字段、不报错
5. 前端 `renderCard` 渲染 chip + 红绿语义（若有前端测试钩子，否则人工验证）

## 风险

- **方向对「谁」是命门**：prompt 与 UI 都须明确，否则误导。
- **A 股红绿语义与西方相反**：UI 配色固定为利多红/利空绿，需注释防回归。
- LLM 幻觉方向：用「把握不足给中性」+ 强度可见 双重缓释。

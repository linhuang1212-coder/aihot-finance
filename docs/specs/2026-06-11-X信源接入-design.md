# X(Twitter)信息源接入 设计文档

> 舆情系统演进 · 子项目 3。2026-06-11。

**Goal:** 把精选 X 账号(财经快讯/OSINT地缘/market mover/自选KOL)的推文接入现有新闻管线,
让 Walter Bloomberg 级别的盘中快讯、地缘 OSINT 早期信号进入推送/打标/发酵体系。

**调研结论(2026-06):** X 官方 API 已无免费读取(按量 $0.005/条,月成本数百美元,出局);
公共 Nitter 实例 2024 年底全灭、自建需账号 session 且有封号风险(出局);
**第三方 twitterapi.io**($0.15/千条,约官方 1/33,高级搜索支持多账号合并查询)为选定方案。

---

## 锁定的设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 接入方式 | twitterapi.io 高级搜索 | 月成本 ≈$4-5;一次调用扫全白名单;纯 urllib 可接 |
| key 存放 | `bot_config.json.twitterapi_key` 或环境变量 `TWITTERAPI_KEY` | 与 deepseek_key 同例,已 gitignore;**无 key 整体静默跳过** |
| 模块边界 | 新建 `xfetch.py` | newsfetch.py 已 800 行;与 llm.py/market.py 同模式 |
| 账号管理 | 新建 `x_watch.json` 配置 | 4 组 16 账号,带组级 verified 标记,改完重启生效 |
| 降噪策略 | `_keep` 对 `X·` 前缀源直接放行 | 白名单 = 人工精选,无需关键词降噪;否则英文非实体推文会被 newsfetch.py:597 误杀 |
| 打分定级 | `_source_tier` 不动(X 按 tier2) | 重要度主要靠 LLM 打分;OSINT 不应享受 tier1 +4 分 |

## 抓取(`xfetch.py`)

- **端点:** `GET https://api.twitterapi.io/twitter/tweet/advanced_search`,header `X-API-Key`
- **查询:** `(from:A OR from:B OR ...) -filter:retweets` 全部 16 账号一条查询 + `since_time=<上次水位>`
- **增量水位:** `data/x_state.json` 存 `last_since_time`(Unix 秒);首跑取当前时间-30分钟(避免历史灌爆);
  本轮成功后推进到本轮发起时间-60秒(重叠 1 分钟防边界丢推,靠 id 去重兜底)
- **分页:** cursor 翻页,**每轮最多 3 页**(成本护栏,约 60 条)
- **节奏:** 搭 server 现有 180 秒刷新,每轮 1-3 次调用;预计 **$4-5/月**
- **失败处理:** timeout=15;任何异常 → print 日志 + 返回 `[]`,水位不推进(下轮重试),绝不拖垮 fetch_all
- **无 key:** `enabled()=False`,`fetch_x()` 返回 `[]`

### 条目映射(推文 → 标准 item)

| 字段 | 值 |
|---|---|
| `id` | `_hash_id("x:" + tweet_id)` |
| `title_zh` | 推文文本翻译(复用 `newsfetch.translate`,懒导入,Google gtx + translations.json 缓存) |
| `title_orig` / `body_excerpt` | 推文原文(截 500 字) |
| `summary_zh` | 同 title_zh(后续 LLM enrich 会覆盖) |
| `published_at` | createdAt → CST ISO |
| `source` | `"X·" + label`(如 `X·Walter Bloomberg`) |
| `source_url` | `https://x.com/<user>/status/<id>` |
| `lang` | `"en"`(中文账号文本本身是中文,翻译缓存原样命中) |
| `verified` | 按组映射 |
| `channels` | `["finance"]`;categories/markets/entities 留空,走管线打标 |
| `dedup_group` | `_hash_id(_norm_title(文本))`(与现有源一致,跨源聚类/发酵自动生效) |

## 管线集成(`newsfetch.py` 两处小改)

1. `fetch_all()` 抓取段追加(try/except 包裹):
   ```python
   try:
       import xfetch
       items.extend(xfetch.fetch_x())
   except Exception as e:
       print("[xfetch] skipped:", e)
   ```
2. `_keep()` 开头加:`if (it.get("source") or "").startswith("X·"): return True`
   ——白名单直通,绕过英文非实体丢弃规则(newsfetch.py:597)。

之后翻译/实体打标/LLM 情绪重要度/去重聚类/mentions 发酵/推送全部自动生效,**无其他特殊化**。

## 测试(TDD,stdlib unittest,新建 `tests/test_xfetch.py`)

1. **解析映射:** 录制的 advanced_search 响应 fixture → 断言 id/title_orig/published_at(CST)/source/source_url/verified 正确
2. **OSINT 标记:** osint 组账号推文 → `verified=="unverified"`;finance 组 → `"confirmed"`
3. **增量水位:** 成功后 x_state.json 推进;失败(mock 抛异常)→ 返回 [] 且水位不动
4. **无 key:** `enabled()=False`、`fetch_x()==[]`,不发任何 HTTP
5. **分页护栏:** mock 返回 has_next_page=True → 最多取 3 页
6. **_keep 放行:** `source="X·Walter Bloomberg"` 的英文无实体条目 → `_keep()==True`(回归:普通英文无实体条目仍被丢)

## 风险

- **第三方服务存续风险:** twitterapi.io 属灰色地带,可能被 X 封堵;`_call` 单点封装,换供应商成本一小时
- **mover 组推文量:** Elon/Trump 高产,若日费用异常(>$0.5/天)或推送被刷屏,后续给 mover 组加 LLM 重要度≥5 的组级门槛
- **翻译预算:** 推文走 `_translate` 共享每轮预算(budget_max),高峰期部分推文当轮保留英文、下轮补翻——现有 RSS 源同等行为,可接受

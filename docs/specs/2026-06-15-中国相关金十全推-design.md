# 中国相关金十全推 设计文档

> 信源策略 · 子功能。2026-06-15。

**Goal:** 金十信源里**跟中国及中国企业相关(宽口径)**的条目,**全部强制进精选 + 推送**——绕过现有的重要度阈值,确保不漏。

**背景(代码探查):**
- `selected` 同时驱动网页「精选」**和** Telegram 推送(`telegram_bot._worth_push` 的门槛就是 `it.get("selected")`)。所以把条目标为 `selected` 即同时满足两者,**bot 端无需改**。
- 现有「中国相关」识别只有 A股股市信号(`MARKET_KEYWORDS["a-share"]`=沪深指数/涨停 等、`CAT_KEYWORDS["ashare"]`),覆盖不到「中国企业/中国宏观/中概股/对华政策」这种宽范围。本设计补一个宽口径识别器。

---

## 锁定的设计决策

| 决策 | 选择 |
|---|---|
| 「发」含义 | **推送 + 精选都要** —— 直接把命中条目标为 `selected`(两者绑定,一举两得) |
| 中国口径 | **宽口径** —— 凡讲中国或中国公司:A股+港股中资+中概股+未上市中企+中国宏观/央行/人民币/政策+对华政策 |
| 识别方式 | **方案1:关键词 + 实体(零依赖、确定性、永远在线)**;LLM `china` 标志留作日后增强 |
| 作用范围 | **仅金十**(`source == "金十"`);X 及其它源不受影响 |
| 噪音/非财经 | 照常过滤(不绕过 `_keep` / `llm_fin`);本功能只覆盖**重要度阈值**这一关 |

## 识别器(newsfetch)

```python
def _is_china_related(it):
    """宽口径:跟中国/中国企业相关。关键词 ∪ 实体市场(a-share/hk) ∪ ashare 分类/市场。"""
    text = _all_text(it)                      # 与 _score 同款文本(已 lower)
    if any(k in text for k in CN_KEYWORDS):   # CN_KEYWORDS 中文 + 小写英文
        return True
    if any(e.get("market") in ("a-share", "hk") for e in it.get("entities", [])):
        return True
    if "ashare" in it.get("categories", []):
        return True
    ms = it.get("markets", [])
    return "a-share" in ms or "hk" in ms
```

## 强制选中(newsfetch.fetch_all)

在 `fetch_all` 的"打分 + 精选判定"循环里,两条评分路径(`_score` 与 LLM 路径)算完 `it["selected"]` 之后、`heat` 之前,加:

```python
        if it.get("source") == "金十" and _is_china_related(it):
            it["selected"] = True
```

效果:命中条目 `selected=True` → 进网页精选 + 过 `_worth_push` 被推送。非金十、或金十非中国相关,行为不变。

## 边界

- 噪音(`NOISE_KW`/`JUNK_SOURCES`)、非财经(`llm_fin is False`)仍先被过滤——本功能只松「重要度」这一关,不复活垃圾。
- 量级:金十本是中文财经源,中国相关占比高 → 精选/推送量会明显上升(用户明确要"全部",符合预期)。
- 零依赖照旧;`telegram_bot.py` 不改。

## 不在本期范围

- **同事件多推合并**(功能 B,独立排期)。
- LLM `china` 标志增强(召回更高,但 LLM 可关,先不依赖)。
- 对 X 或其它源套用同规则(本期仅金十)。

## 测试(TDD,stdlib unittest)

1. `_is_china_related`:
   - 含"中国/央行/人民币/A股/比亚迪/华为"等关键词 → True。
   - 实体 `market="a-share"`(或 `hk`)→ True;`categories=["ashare"]` → True;`markets=["a-share"]` → True。
   - 纯美股/中东/无中国信号("美联储降息""伊朗导弹")→ False。
2. `fetch_all` 强制选中(构造 reps 直测或抽函数):
   - `source="金十"` + 中国相关 + 低分(本不该 selected)→ `selected=True`。
   - `source="金十"` + 非中国 + 低分 → `selected` 不被强制(维持原判)。
   - `source="X·…"` + 中国相关 + 低分 → 不强制(仅金十)。
